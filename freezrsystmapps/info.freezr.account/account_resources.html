Claude Code (local subscription)

Enable Claude Code (local subscription)

Routes LLM calls through the claude command-line tool installed and logged in on this server, so they use your own Claude subscription instead of a metered API key. freezr never reads or stores your Claude credentials — it only runs the binary below and reads its output. Usage counts against your subscription's normal limits (the same pool as your interactive Claude Code use), and calls report a cost of $0.

Which apps can use this: by default, only the Creator app — the one you build apps with. Other apps will not see it as an option, even after you enable it here. Two reasons: these calls spend your own Claude subscription rather than a metered API key, and the provider's terms cover a subscription holder's own personal and development use, not serving other people from it. Your server administrator can lift this by setting the SHOW_LOCAL_AGENT_IN_APPS=true environment variable — at their own risk.

Detected automatically where possible. Must be a file named claude.

OpenAI Codex (local subscription)

Enable OpenAI Codex (local subscription)

Routes LLM calls through the codex command-line tool installed and logged in on this server (signed in with your ChatGPT account), so they use your ChatGPT subscription instead of a metered API key. freezr never reads or stores your OpenAI credentials — it only runs the binary below and reads its output. Usage counts against your plan's Codex limits, and calls report a cost of $0.

Which apps can use this: by default, only the Creator app — the one you build apps with. Other apps will not see it as an option, even after you enable it here. Two reasons: these calls spend your own ChatGPT subscription rather than a metered API key, and Codex runs an agent: command execution is switched off, but no single setting has been proven to remove every action it could take, so it should not be fed untrusted content such as other people's emails or messages. Your server administrator can lift this by setting the SHOW_LOCAL_AGENT_IN_APPS=true environment variable — at their own risk.

Detected automatically where possible. Must be a file named codex.

Connected Accounts

Connect a Gmail, Microsoft or Slack Account

Authorize freezr to access external services on your behalf. OAuth accounts (Gmail) use "Connect Account"; IMAP mailboxes (Yahoo, iCloud, Fastmail, self-hosted) use "Add IMAP Mailbox" with an app password. The mail app works the same way for both. Slack workspaces can also be added directly with a User OAuth Token — useful when the OAuth flow isn't set up (e.g. localhost without https).

File Stores

Add a Local Folder as a File Store

Lets apps you explicitly authorize (via the use_file_sys permission) browse and read the files in one folder on this server's machine — for example to send documents to an AI app for analysis. Apps see everything inside the folder, so pick the narrowest folder that works. The folder may not overlap the freezr installation directory, and access only works for admin users on localhost.

Letters, digits, underscore and dash only. Apps refer to the store by this name.

This is the store's ceiling — each app's grant can be narrowed further, and write access additionally requires the app's permission to carry the write scope.

Add Slack Workspace (token)

Paste a User OAuth Token (xoxp-…) from your Slack app: api.slack.com/apps → your app → OAuth & Permissions → Install to Workspace. Add the user-token scopes there first (channels/groups/im/mpim :read + :history, users:read, and chat:write + the *:write scopes for sending / mark-read). The token is encrypted at rest.

Letters, digits, underscore and dash only. Used by apps to refer to this workspace.
