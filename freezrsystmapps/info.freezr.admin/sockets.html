Messaging Sockets

Server-held live connections to messaging providers (Slack today). A socket runs only when all three are in place: the master switch on the Preferences page, an enabled admission below (the explicit capability grant), and the provider's credential (for Slack: the app-level xapp-… token on the OAuth setup page). Each user additionally opts their own connection in on Account Resources.
